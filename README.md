# Abhinav Bajpai Portfolio

Professional portfolio website for GitHub Pages.

## Files
- `index.html` - website content
- `style.css` - responsive design
- `script.js` - menu, reveal animations and year
- `resume.pdf` - add your own resume PDF here

## Before publishing
1. Your email has been added to `index.html`.
2. Your supplied resume is already included as `resume.pdf`.
3. Review all experience/project wording.
4. Do not publish confidential company information, internal IPs, server names, screenshots or secrets.

## GitHub Pages
Recommended repository name for a personal site:

`abhinav-bajpai-12.github.io`

Then enable GitHub Pages from the repository's Settings > Pages and publish the `main` branch/root.
